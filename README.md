# Exploratory Data Analysis — лабораторная работа 3

Это учебная лабораторная работа для знакомства с Data Science и погружения в
анализ данных. В ноутбуке исследуются наборы данных об успеваемости учащихся и
фильмах с помощью статистических показателей, корреляционного анализа и
визуализаций.

## Файлы данных

- `Students.csv` — сведения об учебных результатах и связанных признаках.
- `films.csv` — данные о фильмах, оценках, бюджетах, доходах и жанрах.

Ноутбук и оба CSV должны находиться в одной папке.

## Запуск

Откройте `ИАД_РТ_3.ipynb` в Jupyter Notebook или VS Code и выполняйте ячейки
по порядку. Требуются Python и библиотеки `numpy`, `pandas`, `matplotlib`,
`seaborn` и `scipy`.
